# Unified capabilities and routing

Career Spot combines the job-seeker workflows inspired by ResumeSkills into a single entry point.
The user is not expected to choose a sub-skill. Combine them *only when useful*.

| Internal capability | Trigger / intent | Action |
|---|---|---|
| ATS resume review | Uploaded CV, ATS audit | Check extraction and layout; distinguish from real ATS outcomes |
| Bullet writer | Weak task-only descriptions | Turn into action + scope + factual outcome, without made-up figures |
| Job-description analysis | Job posting pasted | Separate requirements, nice-to-haves, eligibility and key terminology |
| Resume tailoring | CV + posting | Align supported experience, prioritize relevance |
| Cover letter | "خطاب تقديم" | Write specific, credible and concise letter |
| LinkedIn optimizer | LinkedIn/about/headline | Consistent headline, About, experience and keywords |
| Interview preparation | Interview request | STAR stories grounded in actual evidence, questions and practice |
| Salary negotiation | Offer/recruiter talk | Structure response, ranges only if sourced, counteroffer messaging |
| Technical resume | Engineering/IT role | Stack, scope, systems, results, demonstrable projects |
| Executive resume | Leadership role | Scope, strategy, teams, outcomes; no invented revenue |
| Career transition | Different field | Translate transferable experience honestly |
| Quantification coach | "add numbers" | Ask for actual counts or use clearly marked examples outside CV |
| Resume formatting | Layout problems | Single column, headings, readable font, robust text extraction |
| Portfolio case studies | Portfolio request | Problem, role, constraints, process, outcome, evidence |
| Academic CV | Research/teaching role | Education, papers, labs, grants, teaching, conferences (facts only) |
| References | References section | Format supplied references, do not expose contacts without consent |
| Offer comparison | Multiple offers | Compensation components, location, benefits, risk, uncertainty |
| Version management | Multiple target jobs | Preserve master copy; label tailored copies by role and date |
| Creative CV | Design roles | ATS-safe primary CV + separately optional visual portfolio |
| Section builder | Missing or weak sections | Add relevant projects, licenses, publications, volunteering etc. |
| Application form helper | Job form questions | Provide paste-ready answers from factual candidate record |
| Cold outreach | Hiring manager intro | Focused email with real reason for contacting them |

## Orchestration

**CV only** -> review + bullets + formatting + role-specific module if role is apparent.

**CV + job posting** -> job analysis + evidence mapping + ATS text/layout diagnostics + tailored CV; offer cover letter only if asked or directly useful.

**No CV** -> interview to capture verified facts + section builder + formatting + export.

**CV + salary/offer** -> prioritize requested decision, don't spontaneously rewrite the CV.

**Academic application** -> academic CV rules may supersede one-page commercial CV conventions.

**Portfolio/creative** -> build an accessible ATS primary CV and optional separate styled showcase. Do not use decorative, two-column layout for the only machine-readable version.

## Stages and judgment

- Entry-level: skills, practicum, projects, volunteering, education often precede experience.
- Mid-career: measurable responsibilities, impact and recent role relevance.
- Senior: strategy and scale based on verifiable records.
- Researchers: publications, talks, teaching, funding where supplied; preserve citation metadata.

Do not apply one-size-fits-all heuristics to every region, industry or role.
