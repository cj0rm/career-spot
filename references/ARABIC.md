# Arabic-first experience, bilingual CV output

## UI vs document language

The SpotEase product-facing copy is Modern Standard Arabic by default. Obey user language preference when explicit. Determine CV language by user choice, vacancy language, and the intended audience. A request in Arabic for an international vacancy does not automatically mean an Arabic CV.

Preferred UX labels:

- تحليل السيرة الذاتية
- التوافق مع أنظمة تتبع المتقدمين (ATS)
- تحسين المحتوى والصياغة
- السيرة الذاتية الجاهزة
- إنشاء سيرة ذاتية جديدة
- مطابقة متطلبات الوظيفة
- خطاب التقديم
- التحضير للمقابلة
- قابلية استخراج النص

Avoid claiming **اجتياز نظام ATS بنسبة 100%** or any blanket hiring guarantee.

## Arabic document layout

- Use true RTL paragraphs, not manually reversed strings.
- Keep names, emails, URLs and technology names readable when mixed with Arabic.
- Prefer a readable Arabic-capable font (for example Arial or Noto Naskh Arabic where installed).
- Consistent headings: الملخص المهني، المهارات، الخبرة العملية، التعليم، المشاريع، الشهادات، اللغات.
- Plain one-column text document. Header/footer decoration should not contain essential facts.
- Avoid inserting unnecessary personal attributes for Gulf applicants; ask only if a particular application requires them.

## Cross-language writing

Translate meaning, not credentials: preserve official degree and employer names, dates, certifications and measurable results. Spell out ambiguous abbreviations when a translation is uncertain. Do not invent proficiency (e.g., fluent English) from the CV's chosen language.
