## ما هي Career Spot؟

**Career Spot** مهارة موحّدة (Agent Skill) تجمع **22 سير عمل مهني** في تجربة واحدة. أرسل سيرتك الذاتية ليحلّلها الوكيل ويقترح التحسينات ويُنشئ نسخة كاملة قابلة للاستخدام، أو اطلب إنشاء سيرة جديدة من البداية. وتساعدك أيضًا على مواءمة السيرة مع إعلان وظيفة، وإعداد خطاب تقديم والاستعداد للمقابلة.

| المجال | ما الذي تقدّمه المهارة؟ |
|:--|:--|
| **تحليل السيرة** | قراءة ملفات PDF النصية وDOCX، واكتشاف نقاط الضعف والتناقضات. |
| **ATS والتنسيق** | تقييم قابلية استخراج النص ومخاطر التنسيق، وإنشاء تخطيط واضح أحادي العمود. |
| **تحسين السيرة** | تطوير الملخص والمهارات وصياغة الإنجازات دون اختلاق بيانات. |
| **إنشاء سيرة جديدة** | بناء سيرة كاملة من المعلومات التي يقدّمها المستخدم، حتى لو كان حديث التخرج. |
| **مطابقة الوظائف** | مقارنة المؤهلات بمتطلبات الإعلان، وإبراز الأدلة والفجوات الفعلية. |
| **دعم التقديم** | خطاب تقديم، LinkedIn، استعداد للمقابلات، ملفات أعمال، وغيرها. |

> [!IMPORTANT]
> **Career Spot ليست نظام ATS حقيقيًا ولا تضمن اجتياز فحص توظيف أو الحصول على وظيفة.** تميّز المهارة بين جودة تنسيق الملف ومدى توافق الخبرات مع إعلان الوظيفة. يجب مراجعة جميع البيانات قبل إرسالها.

## ابدأ في أقل من دقيقة

**التثبيت باستخدام Skills CLI:**

```bash
npx skills add https://github.com/cj0rm/career-spot --skill career-spot -a codex
```

**الاستخدام في Codex:**

```text
$career-spot حلّل سيرتي الذاتية المرفقة، ثم أعد لي نسخة محسّنة متوافقة مع معايير القراءة الشائعة في ATS.
```

يمكنك أيضًا تثبيت المهارة يدويًا بنسخ ملفات المشروع إلى `~/.agents/skills/career-spot`، مع الاحتفاظ بـ `SKILL.md` في الجذر. [اقرأ دليل التثبيت](docs/INSTALLATION.md).

## أمثلة للاستخدام

```text
$career-spot أنشئ لي سيرة ذاتية جديدة لوظيفة مهندس عمليات من معلوماتي.

$career-spot افحص السيرة المرفقة، وبيّن أخطاء الصياغة والتنسيق، ثم صدّر DOCX محسّنًا.

$career-spot قارن سيرتي بإعلان هذه الوظيفة، وعدّل صياغتها دون إضافة خبرة غير موجودة.

$career-spot اكتب خطاب تقديم مبنيًا على سيرتي وإعلان الوظيفة.
```

[المزيد من الأمثلة ومسارات الاستخدام](docs/EXAMPLES.md)

## كيف تعمل المهارة؟

```text
ملف CV أو طلب إنشاء جديد
          │
          ▼
  قراءة المعلومات والتحقق منها
          │
          ▼
    تحليل ATS والمحتوى
          │
          ▼
  تحسين أو إنشاء السيرة كاملة
          │
          ▼
  مطابقة الوظيفة (عند توفير إعلان)
          │
          ▼
   نسخة جاهزة + DOCX / PDF عند توافر الأدوات
```

**توضيح تقني:** ملفات المهارة توجه وكيل AI متوافقًا، بينما أدوات Python المرفقة تستخرج النص وتُنشىء المستندات. لا تتصل السكربتات بنموذج AI وحدها. يلزم LibreOffice لتصدير PDF، وتحتاج الملفات الممسوحة ضوئيًا إلى OCR إضافي.

## تشغيل أدوات المستندات

عند الحاجة إلى استخراج ملف أو توليد DOCX/PDF محليًا:

```bash
python -m pip install -r requirements.txt
python scripts/validate.py
python -m unittest discover -s tests -v
python scripts/build_cv.py examples/sample_cv_en.json --outdir exports
python scripts/build_cv.py examples/sample_cv_ar.json --outdir exports
```

وللتصدير إلى PDF، أضف `--pdf` بعد تثبيت LibreOffice. الوثائق: [التكامل التقني](docs/INTEGRATION.md).

## الجودة والخصوصية والحدود

- واجهة افتراضية بالعربية؛ أما لغة السيرة نفسها فتُحدّد وفق إعلان الوظيفة وطلب المستخدم.
- لا تختلق تواريخ أو شهادات أو خبرات أو أرقام إنجاز.
- تدقيق ATS استرشادي قابل للتفسير، وليس اختبارًا مباشرًا لدى أنظمة أصحاب العمل.
- يُفضّل DOCX النصي عند السماح به، مع التحقق من قابلية استخراج النص من الملفات المصدّرة.
- لا تُرفع الملفات إلى خدمة خارجية بمجرد تثبيت المهارة؛ لكن استخدام نموذج سحابي لمعالجة السيرة يخضع للخدمة التي يشغّلها المستخدم.
- قد يتعذّر تحليل PDF الممسوح ضوئيًا دون OCR؛ وللمخرجات العربية قيود تختلف بحسب أدوات قراءة ATS.
