## ما هي Career Spot؟

**Career Spot** مهارة موحّدة لوكلاء الذكاء الاصطناعي تساعدك على تطوير سيرتك الذاتية وخطوات التقديم الوظيفي في تجربة واحدة.

إذا كانت لديك سيرة ذاتية، يمكنك طلب تحليلها وتحسينها وإعادة صياغتها. وإذا كنت تبدأ من الصفر، تساعدك المهارة على إنشاء سيرة منظّمة بالاعتماد على معلوماتك الحقيقية. كما يمكنك إرفاق وصف وظيفي لتكييف السيرة مع متطلبات الوظيفة.

## ماذا تقدّم لك؟

| المجال | الإمكانات |
|:--|:--|
| **تحليل السيرة الذاتية** | مراجعة المحتوى، الأقسام، الصياغة، وقابلية استخراج النص. |
| **تحسين التوافق مع ATS** | اقتراح تنسيق واضح يسهل قراءته آليًا، وتحديد الكلمات المفتاحية المناسبة. |
| **تحسين السيرة الحالية** | إعادة كتابة الملخص والخبرات والإنجازات بلغة مهنية دقيقة. |
| **إنشاء سيرة جديدة** | بناء سيرة من البداية للطلاب والخريجين وأصحاب الخبرة. |
| **مطابقة إعلان وظيفي** | مقارنة متطلبات الوظيفة بالمؤهلات الفعلية وتخصيص محتوى السيرة. |
| **مساندة التقديم** | إعداد خطابات التقديم، وتحسين LinkedIn، والتحضير للمقابلات. |
| **مستندات جاهزة للاستخدام** | إعداد محتوى منسّق مع إمكانية التصدير إلى DOCX وPDF عند توافر أدوات المستندات. |

تجمع المهارة **22 مسارًا وظيفيًا** وتختار الخطوات المناسبة وفق طلب المستخدم.

## ابدأ في أقل من دقيقة

ثبّت المهارة باستخدام Skills CLI مع Codex:

```bash
npx skills add https://github.com/cj0rm/career-spot --skill career-spot -a codex
```

بعد التثبيت، افتح وكيل الذكاء الاصطناعي واستخدم المهارة في محادثتك:

```text
$career-spot حلّل سيرتي الذاتية المرفقة، ثم أنشئ نسخة محسّنة لوظيفة مهندس كيميائي.
```

[دليل التثبيت الكامل](docs/INSTALLATION.md)

## أمثلة على الاستخدام

**لتحليل سيرة موجودة**

```text
$career-spot راجع سيرتي الذاتية، وحدّد أخطاء التنسيق والصياغة وفرص تحسين قراءة ATS.
```

**لإنشاء سيرة جديدة**

```text
$career-spot أنشئ لي سيرة ذاتية احترافية من الصفر، وابدأ بجمع المعلومات الأساسية.
```

**لمطابقة وظيفة محددة**

```text
$career-spot قارن سيرتي بإعلان هذه الوظيفة، ثم أعد صياغتها لإبراز خبرتي المناسبة.
```

**لإعداد طلب توظيف متكامل**

```text
$career-spot حسّن سيرتي الذاتية واكتب خطاب تقديم مخصصًا، ثم جهّز أسئلة مقابلة محتملة.
```

[المزيد من الأمثلة](docs/EXAMPLES.md)

## كيف تعمل؟

```text
سيرة ذاتية موجودة أو معلومات جديدة
                 ↓
      فهم الخبرات والمؤهلات
                 ↓
  تحليل المحتوى والتنسيق ومتطلبات ATS
                 ↓
    تحسين السيرة أو إنشاؤها
                 ↓
  تخصيصها للوظيفة، عند الحاجة
                 ↓
       مراجعة النسخة النهائية
```

## الجودة والموثوقية

تعمل Career Spot على تحسين عرض المؤهلات الحقيقية دون اختلاق خبرات أو شهادات أو إنجازات. وتقدّم مراجعة استرشادية لقابلية قراءة ATS، وليست نتيجة اختبار صادرة عن نظام توظيف محدّد. يُفضّل مراجعة المعلومات النهائية قبل إرسال أي طلب وظيفي.
