# Contributing / المساهمة

Open a GitHub issue describing the problem, a reproducible example, and any
unsupported ATS/content assumptions. Pull requests should include a unit test
when changing parsing or document generation. Never commit real CVs, private
contact details, model keys, or confidential job applicant data.

For Arabic changes, verify readable right-to-left output, consistent technical
terminology, and correct treatment of mixed English text. Claims about ATS
compatibility must be evidenced and never promise acceptance by a specific
recruiting platform.
