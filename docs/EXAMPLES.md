# أمثلة استخدام Career Spot

الطلبات التالية تُرسل إلى وكيل متوافق مع Skills بعد تثبيت المهارة.

## 1. تحليل وتحسين سيرة موجودة

```text
$career-spot حلّل السيرة المرفقة، وراجع التواريخ والمهارات والصياغة ومخاطر تنسيق ATS، ثم أنشئ سيرة كاملة محسّنة دون اختراع معلومات.
```

**المخرجات:** ملاحظات مختصرة، ومؤشرات قابلة للتفسير، وسيرة كاملة قابلة للنسخ؛ وDOCX/PDF إذا كانت أدوات المستندات متاحة.

## 2. بناء سيرة جديدة

```text
$career-spot أريد إنشاء CV بالإنجليزية لوظيفة Chemical Engineer. اسألني عن المعلومات الناقصة الضرورية فقط، ثم أنشئ النسخة النهائية.
```

**المخرجات:** سيرة مرتبة بحسب المرحلة المهنية دون اختلاق سنوات خبرة أو إنجازات.

## 3. مواءمة السيرة مع إعلان وظيفة

```text
$career-spot هذه سيرتي وهذا إعلان الوظيفة. قارن المتطلبات بمهاراتي، وبيّن ما يمكن إثباته وما ينقصني، ثم صغ نسخة مخصصة للوظيفة.
```

**المخرجات:** جدول الأدلة والفجوات، وسيرة مخصصة بالمعلومات المؤكدة فقط.

## 4. خطاب تقديم احترافي

```text
$career-spot أنشئ خطاب تقديم رسمي من صفحة واحدة بناءً على السيرة وإعلان الوظيفة المرفقين.
```

## 5. حديث تخرج أو تدريب

```text
$career-spot أنا حديث تخرج ولا أملك خبرة عمل طويلة. استخدم مشاريعي وتدريبي ومهاراتي لإعداد سيرة مهنية من صفحة واحدة.
```

## 6. تحليل ATS فقط دون إعادة كتابة

```text
$career-spot أريد تقريرًا عن قابلية استخراج النص والمخاطر الهيكلية في السيرة فقط، دون إعادة كتابتها.
```

**تنبيه:** لا يُمكن لأي تقرير محلي أن يضمن النجاح لدى نظام ATS تابع لصاحب عمل بعينه.
