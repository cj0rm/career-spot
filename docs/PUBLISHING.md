# نشر Career Spot وعرضها

## 1. المستودع الرسمي

- الكود: https://github.com/cj0rm/career-spot
- التعليمات: [`SKILL.md`](../SKILL.md)
- صفحة العرض: [`web/index.html`](../web/index.html)
- نص بطاقة المكتبة: [`web/PUBLISHING_COPY.md`](../web/PUBLISHING_COPY.md)
- بيانات البطاقة: [`web/skill-card.json`](../web/skill-card.json)

## 2. إضافة المهارة إلى ai.spotease.om

تعرض مكتبة SpotEase AI مهارات متخصصة. أضف بطاقة **Career Spot** برقم `SKILL_002` تحت فئة «المسار المهني والتوظيف» وفق نمط بطاقة Arabic Spot الحالي، مع رابط هذا المستودع وأمر التثبيت:

```bash
npx skills add https://github.com/cj0rm/career-spot --skill career-spot -a codex
```

تُعد بيانات JSON الموجودة في `web/skill-card.json` نموذجًا توضيحيًا وليست مخططًا مضمونًا لبيانات موقعك؛ طابقها مع بنية المشروع الحالي قبل الدمج. لا تغيّر تصميم الموقع أو نظام الألوان والخطوط الموجود إلا عند طلب ذلك.

## 3. صفحة تعريفية مستقلة

`web/index.html` صفحة عربية RTL متجاوبة يمكن استضافتها مباشرة على أي استضافة ثابتة. ليست تطبيقًا ينفّذ تحليل CV عبر المتصفح. جميع الأمثلة والأنشطة فيها وصفية.

## 4. تشغيل تطبيق CV تفاعلي

رفع الملف وتحليل محتواه وتحسينه وتنزيله مباشرةً يتطلب واجهة مستخدم متصلة بواجهة خلفية موثّقة ونموذج AI وأدوات معالجة الملفات. يوفّر المشروع `api/server.py` خدمات استخراج الملفات وتصديرها فقط. اتّبع [`docs/INTEGRATION.md`](INTEGRATION.md) قبل إطلاق أي خدمة عامة، خصوصًا في ما يتعلق بالتحقق والأمان والخصوصية.
