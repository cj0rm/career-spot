# تثبيت Career Spot

## عبر Skills CLI

يتطلب هذا الأسلوب Node.js وبيئة Codex أو وكيلًا متوافقًا مع Agent Skills:

```bash
npx skills add https://github.com/cj0rm/career-spot --skill career-spot -a codex
```

تأكّد من ظهور المهارة في قائمة Skills لدى الوكيل. قد تختلف واجهة تثبيت المهارات بحسب إصدار أداة CLI.

## التثبيت اليدوي

1. نزّل المستودع أو انسخه محليًا.
2. انسخ ملفات المشروع إلى مجلد `~/.agents/skills/career-spot` (أو مسار Skills المعتمد لدى وكيلك).
3. تأكّد من وجود `SKILL.md` في الجذر وملفات `references/` بجواره.
4. أعد تحميل قائمة المهارات في الوكيل إن لزم.

## مثال استعمال

```text
$career-spot أريد سيرة ذاتية جديدة لوظيفة مهندس كيميائي، ابدأ من المعلومات التي أرسلها لك.
```

## أدوات المستندات الاختيارية

تتطلب أدوات استخراج الملفات وتوليد DOCX Python 3.10 أو أحدث:

```bash
python -m pip install -r requirements.txt
python scripts/validate.py
python -m unittest discover -s tests -v
```

يتطلب تصدير PDF وجود LibreOffice مثبتًا على الجهاز أو الخادم. لا توفر هذه السكربتات تحسينًا بالذكاء الاصطناعي دون وكيل AI يستعمل تعليمات المهارة.

## مشكلات شائعة

- **لا تظهر المهارة:** افحص المسار وملف `SKILL.md` وأعد تحميل المهارات.
- **ملف PDF لا يُقرأ:** قد يكون صورة ممسوحة ضوئيًا تحتاج OCR.
- **فشل PDF export:** تأكّد من وجود LibreOffice؛ يمكن استخدام DOCX مؤقتًا.
- **أخطاء استخراج النص:** جرّب ملف DOCX نصيًا أو تأكّد من إمكانية تحديد النص داخل PDF.
